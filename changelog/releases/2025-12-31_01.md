# Dark Matter Website — Release v0.2.4

**Release Date:** December 31, 2025
**Version:** 0.2.4
**Status:** Production-Ready

## What's New Since v0.2.3

v0.2.3 introduced the Reveal.js slide deck system. v0.2.4 focuses on content enhancement—transforming how code and diagrams are displayed across the site with Shiki syntax highlighting and Mermaid.js diagram support.

### Summary of Changes

| Category | v0.2.3 | v0.2.4 |
|----------|--------|--------|
| Code Blocks | No syntax highlighting | Shiki tokyo-night theme |
| Code Block UI | Raw `<pre>` elements | Compact header + copy button |
| Light Mode Code | Same as page background | Always dark for contrast |
| Diagrams | Not supported | Mermaid.js client-side rendering |
| Hero Effects | N/A | 3 CSS glow effect components |

## Key Features

### 1. Shiki Syntax Highlighting

Integrated Shiki syntax highlighting throughout the site using dual themes configured for automatic switching.

**Configuration:** `astro.config.mjs`

```javascript
markdown: {
  shikiConfig: {
    themes: {
      light: 'github-light',
      dark: 'tokyo-night',
    },
    wrap: true,
  },
},
```

**Design Decision: Always-Dark Code Blocks**

Code blocks maintain a dark background (`#1a1b26` tokyo-night) in ALL visual modes:

| Page Mode | Code Background | Syntax Colors | Visual Effect |
|-----------|-----------------|---------------|---------------|
| Dark | `#1a1b26` | tokyo-night | Seamless integration |
| Vibrant | `#1a1b26` | tokyo-night | Subtle contrast |
| Light | `#1a1b26` | tokyo-night | Strong contrast, "pops" |

This approach provides consistent developer experience and follows patterns used by GitHub, VS Code docs, and major documentation sites.

### 2. Compact Code Block Headers

Every code block now features a slim header with:

- **Language label** (uppercase, lilac accent color)
- **Copy button** with "Copied!" feedback
- **Minimal height** (~24px vs typical 32-40px)

```css
.codeblock-header {
  padding: 0.25rem 0.75rem;
  font-size: 0.65rem;
  min-height: 1.5rem;
}
```

### 3. Mermaid Diagram Rendering

Added support for Mermaid.js diagrams in markdown content using client-side rendering.

**The Challenge:**
When using `rehypeShiki`, mermaid code blocks get syntax-highlighted as regular code, preventing Mermaid.js from rendering them.

**The Solution:**
Created `rehypeMermaidPre`—a custom rehype plugin that runs BEFORE Shiki to extract mermaid blocks:

```typescript
function rehypeMermaidPre() {
  return (tree) => {
    visit(tree, 'element', (node) => {
      // Convert <pre><code class="language-mermaid">
      // to <pre class="mermaid">
      // This format won't match rehypeShiki's selector
    });
  };
}
```

**Pipeline Order (Critical):**

```typescript
const processor = unified()
  .use(remarkParse)
  .use(remarkGfm)
  .use(remarkRehype)
  .use(rehypeMermaidPre)  // BEFORE Shiki!
  .use(rehypeShiki)
  .use(rehypeStringify);
```

**Theme Integration:**

Mermaid diagrams use matter-theme colors:

| Variable | Value | Purpose |
|----------|-------|---------|
| primaryColor | `#6643e2` | Node backgrounds |
| primaryTextColor | `#F9FAFB` | Text on nodes |
| primaryBorderColor | `#9C85DF` | Node borders |
| lineColor | `#9C85DF` | Connector lines |
| background | `#0F0923` | Diagram background |

### 4. ContentEnhancer Component

New unified wrapper component that handles BOTH code blocks AND Mermaid diagrams:

```astro
<ContentEnhancer>
  <div set:html={htmlContent} />
</ContentEnhancer>
```

**Features:**
- Enhances all `<pre>` elements with headers/copy buttons
- Detects mermaid blocks and initializes Mermaid.js
- Loads Mermaid from CDN only when needed
- Configurable via props: `enhanceCodeblocks`, `enableMermaid`, `mermaidTheme`

### 5. CSS Hero Glow Effects Library

Three new pure-CSS glow effect components for hero sections:

| Component | Effect |
|-----------|--------|
| `HeroGlow--NucleusPulse` | Pulsing nucleus with orbital rings |
| `HeroGlow--OrbitalCosmos` | Cosmic orbital animation |
| `HeroGlow--RadiantBurst` | Radial burst effect |

**Location:** `src/styles/hero-glows/`

**Usage:**
```astro
<div class="hero-section hero-glow--nucleus-pulse">
  <!-- Hero content -->
</div>
```

## Bug Fixes

### Variable Naming Collision

Fixed a critical bug in `ContentEnhancer.astro` where the function name `enhanceCodeblocks()` collided with the prop variable `enhanceCodeblocks`, causing the conditional check to always pass.

**Before (Bug):**
```javascript
function enhanceCodeblocks() {
  if (!enhanceCodeblocks) return; // Always truthy!
}
```

**After (Fixed):**
```javascript
const shouldEnhanceCodeblocks = enhanceCodeblocks;
function processCodeblocks() {
  if (!shouldEnhanceCodeblocks) return; // Correct
}
```

## Upgrade Path

No action required. Code blocks automatically render with syntax highlighting, and mermaid diagrams render when detected.

To use the new components directly:

```astro
---
import ContentEnhancer from '@components/content/ContentEnhancer.astro';
import BaseCodeblock from '@components/codeblocks/BaseCodeblock.astro';
import MermaidDiagram from '@components/diagrams/MermaidDiagram.astro';
---

<!-- For markdown content -->
<ContentEnhancer>
  <div set:html={htmlContent} />
</ContentEnhancer>

<!-- For direct code embedding -->
<BaseCodeblock code="const x = 1;" lang="typescript" />

<!-- For direct mermaid diagrams -->
<MermaidDiagram>
  graph TD
    A --> B
</MermaidDiagram>
```
